05 — Embedded Systems & Control
Arduino-Based Room Temperature Monitoring & Control System
ENGR 315 · Dec 2024

Built a closed-loop temperature control system using Arduino to simulate room climate management. The system uses dual thermistors to monitor ambient and hot-air inflow temperatures, a relay-controlled heater cycling every 60 seconds, and an exhaust fan that activates at a 89.5°F threshold. All sensor data was visualized in real-time via a custom Tableau dashboard.

Closed-loop feedback control maintaining temperature within 85–95°F band across steady-state cycles
Arduino C++ firmware with thermistor calibration using Steinhart-Hart equation (Beta = 3950)
Tableau real-time dashboard displaying ambient vs. hot air temperature, fan state, and cycle timing
Subsystem integration: servo motors (PWM), DC motors (H-bridge), LCD display, and relay control
